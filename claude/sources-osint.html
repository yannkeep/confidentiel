Questions fréquentes

Comment archiver une page web comme preuve OSINT ?
1) Sauvegarder via Wayback Machine (archive.org/web) qui horodate automatiquement, 2) Prendre un screenshot avec URL et date visibles, 3) Calculer le hash SHA256 du fichier (sha256sum fichier), 4) Optionnel: utiliser OpenTimestamps.org pour un horodatage blockchain.
Comment utiliser Cumuleo pour tracer les mandats d'un élu ?
1) Rechercher le nom sur Cumuleo.be, 2) Consulter tous ses mandats (publics et privés), 3) Voir les rémunérations déclarées, 4) Identifier les cumuls problématiques, 5) Archiver la page comme preuve.
Comment trouver les administrateurs d'une ASBL belge ?
1) BCE (kbopub.economie.fgov.be) → rechercher par nom ou numéro, 2) Section 'Fonctions' pour les administrateurs actuels/passés, 3) Moniteur Belge pour statuts complets et PV d'AG.
Où trouver les décisions de la Cour constitutionnelle belge ?
Sur const-court.be. Recherche par numéro d'arrêt, date, mots-clés, articles de la Constitution. Arrêts en FR et NL. Les recours 8629/8630/8632 contre le décret FWB y sont référencés.
